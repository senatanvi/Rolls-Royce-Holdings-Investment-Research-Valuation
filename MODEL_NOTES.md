# Valuation model

The next version of this project should contain a transparent Excel model rather than relying on an externally generated DCF figure.

Recommended tabs:

1. `Historical Financials`
2. `Assumptions`
3. `Forecast`
4. `DCF`
5. `Sensitivity`
6. `Comps`

## Minimum DCF structure

Revenue
→ EBIT
→ Tax on EBIT
→ NOPAT
→ + D&A
→ - Capex
→ - Change in working capital
→ Unlevered FCF
→ Discount to present value
→ Terminal value
→ Enterprise value
→ + Net cash / - Net debt
→ Equity value
→ Value per share

Keep every major assumption visible and link calculations rather than hard-coding outputs.
